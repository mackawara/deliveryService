## External pilot prerequisites still requiring evidence

No live customer/shop/rider messages or production transactions are authorized in this task. Real template approval/delivery, a physical rider delivery, actual network polling latency at pilot load, and calibration of ETA ranges require the pilot configuration and human-operated procedure in `shop-orders-contract.md`. These are not claimed by the recorded-adapter or fixture tests.

Review follow-ups: failed attempts and returning deliveries remain active until DELIVERED/RETURNED; polling counts use a booking-leading outbox index. Backgrounding preserves both in-flight and unconfirmed command state; stale thresholds scale to three configured poll intervals with a 15-second minimum. These cases have dedicated HTTP, component and browser regressions.
